Better Posters for Jellyfin 12

Fetches customizable primary posters for Movies and Series from https://btttr.cc using validated IMDb IDs (with optional verified TMDB metadata lookup).

Poster Overlay Options

Display top badges such as Trending, New, Award Winner, or IMDb rank when available upstream.
Display 4K, Dolby Vision, and Atmos badges when available upstream.
Display the primary genre label at the bottom of the poster.
Display the score overlay at the bottom of the poster.
Selects which rating service is requested when Ratings are enabled.
Display content certification badges (e.g., PG-13, R, TV-MA).
Preferred language for poster artwork and overlay labels.
When an item has no IMDb ID, query btttr.cc/meta/{movie|series}/tmdb:{id}.json to resolve its canonical IMDb ID before building the poster request.
